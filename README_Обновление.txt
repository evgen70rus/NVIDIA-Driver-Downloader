# NVIDIA Driver Downloader — обновление

## Состав комплекта

- `REPAIR.bat` — запуск обновления.
- `REPAIR.ps1` — загрузка файлов и сборка программы.
- `README_Обновление.txt` — эта инструкция.

## Порядок работы

1. Поместите все три файла рядом с `NVIDIA_Driver_Downloader.exe`.
2. Закройте программу, если она запущена.
3. Запустите `REPAIR.bat`.
4. Дождитесь сообщения «Программа успешно обновлена».

Сценарий скачивает исходный код и иконку из публичного репозитория:
https://github.com/evgen70rus/NVIDIA-Driver-Downloader

Затем собирает EXE с помощью компилятора `csc.exe` из .NET Framework.
Путь к компилятору проверяется в папке `Microsoft.NET\Framework64`, а затем
в `Microsoft.NET\Framework`.

## Требования

- Windows и подключение к интернету.
- Компилятор `csc.exe` из .NET Framework 4.x.

## Важно

- Если загрузка или компиляция завершится ошибкой, новая сборка не будет установлена.
- При ошибке копирования сценарий попытается восстановить прежние файлы.
- Сценарий не исправляет исходный код автоматически. Исправленный код должен
  быть предварительно опубликован в GitHub.
- Репозиторий публичный, поэтому исходный код и иконка доступны всем.
